ශ්‍රී ලංකා තැපැල් කාර්යාල නාමාවලිය — Android Studio Project

මෙය APK එකක් නොව APK එක build කිරීමට සූදානම් කළ Android Studio project එකකි.

Project එකේ අන්තර්ගතය:
- Offline HTML directory එක Android app එකක් ලෙස WebView තුළ විවෘත කරයි.
- Internet permission එකක් අවශ්‍ය නොවේ.
- App label: Post Office Directory
- Minimum Android: Android 6.0 (API 23)

APK එක සෑදීමට:
1. Windows/Mac/Linux පරිගණකයක Android Studio ස්ථාපනය කරන්න.
2. මෙම ZIP එක Extract කරන්න.
3. Android Studio > Open තෝරා SriLankaPostOfficeDirectory project folder එක විවෘත කරන්න.
4. Gradle sync අවසන් වන තෙක් ඉන්න.
5. Build > Build Bundle(s) / APK(s) > Build APK(s) තෝරන්න.
6. APK එක app/build/outputs/apk/debug/app-debug.apk යටතේ ලැබේ.
7. APK එක Android phone එකට යවා install කරන්න. අවශ්‍ය නම් Android Settings තුළින් එම ගොනුව සඳහා install permission දෙන්න.

සටහන: මෙහි පරිසරයේ Android SDK/Gradle build tools නොමැති බැවින් APK binary එක මෙතැනින් compile කර නැත. PDF එකෙන් ලබාගත් postal directory data පරීක්ෂා කළ යුතු අවස්ථා තිබිය හැක.
